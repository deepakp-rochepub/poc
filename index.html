Keyboard lock reachability research PoC

This static research page contains enough visible text to satisfy the Safe Browsing intelligent-scan inner-text threshold in local instrumented builds. Press the button to request fullscreen and then call navigator.keyboard.lock() on the committed page URL. After a successful attempt, the page navigates to the next scan URL so the next click happens on a distinct top-level document. The page is intentionally non-phishing and only demonstrates that an ordinary web page can reach the keyboard-lock client-side detection path.
